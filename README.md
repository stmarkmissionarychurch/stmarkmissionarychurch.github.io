# St. Mark Missionary Baptist Church website

Plain HTML, CSS and a little JavaScript. No build step.

Pages: index.html (Home), about.html, events.html, giving.html, contact.html

## Put it on GitHub Pages (stmarkmissionarychurch.github.io)
1. Open the repository named `stmarkmissionarychurch.github.io` on github.com.
2. Click Add file > Upload files, and drag in everything inside this folder
   (index.html, about.html, events.html, giving.html, contact.html, style.css,
   script.js, and the images and media folders). Commit the changes.
3. Wait about a minute, then visit https://stmarkmissionarychurch.github.io

## Editing text
Open any .html file and change the words. Items in [square brackets] are
placeholders still waiting for real church information.
